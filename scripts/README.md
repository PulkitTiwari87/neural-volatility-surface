# scripts/

Scripts must default to dry-run for anything destructive, never embed secrets, and be documented in [docs/operations/LOCAL_DEVELOPMENT.md](../docs/operations/LOCAL_DEVELOPMENT.md) once they exist. Benchmarks used for decisions (DEC-008/009) are recorded in the corresponding ADR with environment details.
